# Chirag Bhardwaj — Portfolio

Static site, no build step.

- `index.html` — page markup
- `styles.css` — styles (dark-first, auto light theme, reduced-motion safe)
- `script.js` — animations and interactions

## Run locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080

## Deploy

Push this folder to a GitHub repo and enable **GitHub Pages** (Settings → Pages → deploy from `main` / root), or drag the folder onto Netlify Drop / import into Vercel.
